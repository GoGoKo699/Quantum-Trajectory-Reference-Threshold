# Learn the receiver

Start with the [reference-frames bridge](REFERENCE_FRAMES_BRIDGE.md) for a two-sensor example. It shows how one idle qubit lets a receiver identify the rotated sensor while all operations conserve total excitation.

The [30 milestones](MILESTONES.md) develop the physical model, the zero-error condition, the exact reference threshold, and the receiver that attains it. They then connect the finite-budget optimum to a modular design and its resource cost.

The [scientific account](../science/README.md) gives the formal results and proofs. The [implementation](../science/implementation.md) is the direct route to the circuit model and the comparison with local Bell pairs.
