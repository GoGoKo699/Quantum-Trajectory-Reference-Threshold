# Model and moment isolation

A pulse acts on an unknown subset of a sensor array. Its location is the required output. Its angle is an unknown parameter of the experiment. The readout may report an inconclusive result so that a reported location can be used without a subsequent verification shot.

## Interrogation

There are $`N\geq 2`$ sensor qubits and $`r\geq0`$ idle qubits, each with excitation operator $`(I-Z)/2`$. Exactly $`1\leq k\leq\lfloor N/2\rfloor`$ sites are affected, and all size-$`k`$ subsets are possible. For a true subset $`S`$, the one simultaneous interrogation applies

```math
U_S(\theta)=\prod_{i\in S}e^{-i\theta Z_i/2},
\qquad \theta\in I,
```

where $`I`$ is a nonempty open interval and the $`Z`$ axis is known. The control state and readout can depend on the promise but are fixed for every $`\theta`$ and $`S`$. The idle qubits bypass the pulse.

Write $`W`$ and $`B`$ for the sensor and idle excitation operators. Preparation is invariant under common phase rotations generated by $`W+B`$. All readout effects commute with $`W+B`$. A state in a fixed total sector $`Q`$ can be prepared from a charge-$`Q`$ basis state by a conserving unitary. Invariant mixed states are mixtures of pure states in fixed sectors, so pointwise bounds on averaged label success for pure sectors also bound arbitrary mixtures. Classical randomness or a neutral apparatus is allowed. Any bypass system capable of holding compensating excitation during interrogation is included in $`r`$. A neutral outcome register carries a trivial representation. The idle system may be consumed.

The POVM has effects $`E_S`$ for the size-$`k`$ subsets and an abstention effect. For every $`T\ne S`$ and every $`\theta\in I`$, exact identification requires
```math
\langle\psi|U_T(\theta)^\dagger E_S U_T(\theta)|\psi\rangle=0.
```
The optimization is the worst label at each angle. An interval or closed subinterval approaching an identity pulse has infimum success zero even for an ideal reference. We report pointwise success.

## Lower moments are invisible to the conclusive readout

For $`A\subseteq[N]`$ let $`Z_A=\prod_{i\in A}Z_i`$ and $`v_A=Z_A\psi`$. Define $`v_{T,j}=\sum_{A\subseteq T,\,|A|=j}v_A`$. Expanding the interrogation yields
```math
U_T(\theta)\psi
=\sum_{j=0}^k
\cos^{k-j}(\theta/2)\,[-i\sin(\theta/2)]^j\,v_{T,j}.
```
The zero-error condition and positivity give $`E_S^{1/2}U_T(\theta)\psi=0`$ for all wrong $`T`$. On a nonempty open subinterval where cosine is nonzero, division by its $`k`$th power gives a vector-valued polynomial in the tangent. It vanishes on an interval, so each coefficient vanishes. This kills $`v_{T,j}`$ for each wrong $`T`$ and $`j`$.

For $`j<k`$, the inclusion matrix with rows $`T`$ of size $`k`$ and columns $`A`$ of size $`j`$ has entry $`\mathbf{1}_{A\subseteq T}`$. There are fewer columns than rows. The permutation group acts transitively on rows and preserves their linear dependence relations. If any row lay outside the span of the others, every row would, which would contradict row dependence. Thus the wrong rows already span all rows, and $`E_S^{1/2}`$ also kills $`v_{S,j}`$.

The same matrix has full column rank for $`j\leq \min(k,N-k)`$. For a proof, suppose coefficients on its columns give zero on every row. At $`j=0`$ the sole coefficient is zero. For $`j>0`$, compare rows $`R\cup\{a\}`$ and $`R\cup\{b\}`$ with $`|R|=k-1`$ outside distinct $`a,b`$. Their difference uses coefficients $`c_{D\cup\{a\}}-c_{D\cup\{b\}}`$ on $`(j-1)`$-subsets of $`R`$. Induction on the array of size $`N-2`$ makes these differences zero. Any two $`j`$-subsets can be connected by swaps, so all coefficients coincide, and the original row equations force them to vanish. The rank result means $`E_S^{1/2}v_A=0`$ individually for every $`|A|<k`$. At degree $`k`$ it already kills $`v_T`$ for $`T\neq S`$.

For each label,
```math
p(S\mid S,\theta)=\eta_S\sin^{2k}(\theta/2),
\qquad
\eta_S=\langle v_S,E_Sv_S\rangle\in[0,1].
```
This factorization holds for every admissible receiver and makes maximization of the worst-label coefficient $`\eta^*_{N,k}(r)`$ independent of the angle. The same isolated moments imply zero wrong labels under site-dependent rotations on the affected set, with success $`\eta_S\prod_{i\in S}\sin^2(\theta_i/2)`$. This conclusion uses the exact support promise. A nonzero background rotation on nominally untouched sites changes the model.

## The radial bound

A symmetric sum of degree-$`j`$ moments acts on a weight-$`w`$ sensor string as the polynomial
```math
K_j(w)=\sum_{a=0}^{j}(-1)^a\binom{w}{a}\binom{N-w}{j-a},
\qquad
\sum_{|A|=j}v_A=K_j(W)\psi.
```
Its leading coefficient is $`(-2)^j/j!`$, as seen by expanding the two binomial-polynomial leading terms. A degree-$`k`$ polynomial $`P`$ with that same leading coefficient differs from $`K_k`$ by lower degree terms. Since $`K_0,\ldots,K_{k-1}`$ span the lower polynomials, $`E_S^{1/2}P(W)\psi=E_S^{1/2}v_S`$. Summing over labels gives
```math
\sum_{|S|=k}\eta_S
=\langle P(W)\psi,(\sum_{|S|=k}E_S)P(W)\psi\rangle
\leq \|P(W)\psi\|^2.
```
In a sector of total charge $`Q`$ the sensor charge lies in $`[\max(0,Q-r),\min(N,Q)]`$, an integer interval of width at most $`r`$. This is where the counted hardware enters the bound. The [exact endpoints](exact-endpoints.md) and [finite frontier](exact-frontier.md) use this same constraint.
